# 红考拉 · 公开技术基础版

这是餐饮数据处理与经营分析项目的独立技术展示子集，面向代码评审。包含从现有项目抽取的通用校验与菜单逻辑，以及为公开版新增的分层接口、合成示例和测试。它不是完整产品，也不包含菜品图像识别模型。

## 运行

需要 Node.js 24 或更高版本。在本目录执行：

```sh
npm ci
npm run check
npm run demo
```

示例只使用手写合成数据，无需密钥、数据库或联网模型。输出 `implementation: unavailable` 和 `suggestedG: null` 是预期行为，表示核心预测实现未公开。

## 评审入口

| 能力 | 代码 | 可验证证据 |
| --- | --- | --- |
| 输入契约 | `src/domain/dataset.ts` | 日期、单位、状态、非负数、未知字段校验 |
| 数据一致性 | `src/domain/dataset.ts` | 重复键、引用关系、库存守恒、可获得时点 |
| 外部格式适配 | `src/adapters/history-csv.ts` | CSV → 标准克数据 → 业务校验 |
| CSV 解析 | `src/adapters/csv.ts` | BOM、CRLF、引号、换行及列数检查 |
| 菜单作用域 | `src/domain/menu.ts` | 同菜多碗、停用菜品、未映射历史记录 |
| 模块解耦 | `src/application/ports.ts` | 通过接口注入预测实现 |
| 工程验证 | `tests/`、`.github/workflows/ci.yml` | 类型检查、行为测试、公开文件检查 |

## 结构与优化

- `domain`：领域类型和校验，不依赖框架、数据库或预测模型。
- `application`：接收不可信输入，完成校验后调用注入的服务接口。
- `adapters`：CSV 格式转换与缺省预测实现。
- `examples`：可重复运行的合成样例。

原始历史契约中的 CSV 解析、转换和校验已拆为独立模块；菜单过滤移除了对预测及设备完整类型的依赖。数据集校验使用目录索引，避免逐条日记录线性查找菜品。优化仅落在公开副本中，原始应用未被修改。

## 公开范围与限制

公开版不包含生产称重事件引擎、预测与画像算法、模型参数、AI 提示词、设备认证实现、真实数据、数据库、业务界面或部署凭证。CSV 的计件转换仅为原样例适配能力，要求显式提供单件重量，不能视为真实自动计件。

目前没有 HTTP 服务、持久化、生产鉴权或网络模型适配器。测试验证本仓库的基础行为，不证明完整系统预测准确率、并发性能或业务收益。原项目来源与变更见 [来源说明](docs/PROVENANCE.md)，保密边界见 [公开与私有边界](docs/PUBLIC-BOUNDARY.md)。

没有预设开源许可证。公开可见不等同于授予任意复用许可；维护者需按自己的授权意愿另行决定许可证。
